Escribir el script siguiendo el patron de `shadow_gate.py` (`_build_ch_client`, argparse `main`) y `shadow_monitor.py` (query -> DataFrame via result_rows/column_names).

Funciones principales:
- `_build_ch_client()`: copiar el patron exacto de shadow_gate.py (env `ANOMALY_SCORES_CH_*`).
- `resolve_p50(ch_client) -> float`: ejecuta `SELECT quantile(0.5)(percentile) AS p50 FROM {table} WHERE scoring_mode='shadow_new'`; retorna float o fallback 0.5 si vacio. Table via `os.environ.get("ANOMALY_SCORES_CH_TABLE", "pbp_productionDB_optimized.anomaly_scores")` (nota: en Python contra el WRITE local no se usa FINAL salvo que shadow_monitor lo haga — replicar lo que hace shadow_monitor.py; si shadow_monitor NO usa FINAL, no usarlo aqui).
- `compute_counts(top_k, below_p50_pct, capacity) -> (top_k_count, below_k_count)`: MISMA logica que HitlQueueQuery. Funcion pura, facil de testear.
- `build_hitl_queue(ch_client, top_k, below_p50_pct, capacity) -> pd.DataFrame`:
  1. counts = compute_counts(...)
  2. p50 = resolve_p50(ch_client)
  3. df_top = query top-k (SELECT columnas incluyendo top_factors, WHERE scoring_mode='shadow_new' ORDER BY percentile DESC LIMIT top_k_count)
  4. df_below = query below (WHERE scoring_mode='shadow_new' AND percentile < {p50} ORDER BY rand() LIMIT below_k_count)
  5. df_top["hitl_queue_source"]="top_k"; df_below["hitl_queue_source"]="below_p50"
  6. return pd.concat([df_top, df_below], ignore_index=True)
- `write_output(df, path)`: .csv -> df.to_csv, .json -> df.to_json(orient="records"). Crear dir si no existe.
- `main(argv)`: argparse con --top-k, --below-p50-pct, --capacity, --output; imprime resumen (n top_k, n below_p50, p50, ruta de salida) sin filtrar credenciales.

Columnas del SELECT: payment_id, facility_id, facility_name, user_id, scored_at, payment_created_at, amount_usd, raw_score, percentile, risk_level, is_anomaly, model_version, top_factors.

  <name>Task 3: Documentacion de metodologia de falsos negativos</name>
  <files>ml-fraud-detector/docs/hitl_false_negative_methodology.md</files>
  <action>
Escribir el documento (prosa fluida, espanol, estilo tesis — sin redundancia) que justifica el muestreo defensivo below-p50 para estimar falsos negativos. Estructura:

1. **Motivacion**: La cola top-k solo muestra lo que el modelo frame-v1 marca como anomalo (alto percentile). Revisar solo el top-k mide precision pero NO recall — no dice cuantas anomalias reales quedan por debajo del umbral (falsos negativos del proxy de reembolso). Sin muestrear la zona no-alertada, la tasa de FN es inobservable.

2. **Estrategia**: Muestreo estratificado. >=20% de la capacidad de revision se asigna a transacciones con `percentile < p50` (below-p50, no alertadas), seleccionadas pseudo-aleatoriamente (`ORDER BY rand()` / muestreo uniforme). El 20% es el minimo (HITL-03); parametrizable via `--below-p50-pct` segun la capacidad real del equipo (bloqueante conocido: capacidad HITL desconocida — STATE.md).

3. **Estimacion de FN**: Sobre la muestra below-p50 etiquetada por revisores, la fraccion etiquetada como `sospecha_fraude`/`anomalia_operativa` estima la tasa de anomalias reales entre las no-alertadas. Extrapolada al volumen total below-p50, da una cota inferior de falsos negativos. Aclarar que es una ESTIMACION correlacional sobre el proxy, no una medida de fraude verdadero (proxy != fraude; enfoque no supervisado).

4. **Vocabulario de etiquetas**: alinear con las 4 categorias (sospecha_fraude, anomalia_operativa, falso_positivo, indeterminado) — consistencia con hitl_ingest_labels.py y con HitlLabelForm (05-02).

5. **Trazabilidad**: cada etiqueta registra hitl_queue_source (top_k|below_p50), score_at_label_time y model_version_at_label (05-02) — permite reconstruir sin ambiguedad de que estrato y version provino cada caso.

6. **Diferido**: el poblado real depende de >=2 semanas de shadow data (SHAD-03 PENDING_DATA). Este documento + el builder + la query estan listos y probados con datos sinteticos; la operacion arranca cuando el shadow acumule volumen.

Sin lenguaje causal. Sin afirmar que el proxy captura todo el fraude.
